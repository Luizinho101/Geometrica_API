# Geometrica_API
Uma API REST serverless desenvolvida em Node.js e Express, hospedada na Vercel, projetada para automatizar cálculos matemáticos de figuras geométricas. A API fornece endpoints rápidos para calcular área, perímetro e volume de diversas formas bidimensionais e tridimensionais, como triângulos, quadrados, cubos e esferas.
