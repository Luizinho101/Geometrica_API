Documentação da API

API REST para cálculos geométricos simples.

Base URL: http://localhost:3000

POST /api/area/quadrado

Calcula a área de um quadrado a partir do valor do lado fornecido.

Corpo da Requisição (Request Body)

Envie um JSON com a propriedade lado (número positivo).

{
    "lado": 4
}

Resposta de Sucesso (200 OK)

{
  "area": 16
}
